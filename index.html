Deploy JANET WEATHER to GitHub Pages

This dashboard is a single self-contained HTML file with zero build dependencies. Save it as index.html in any GitHub repository and enable Settings → Pages → Deploy from branch (main / root).

Geocoding: geocoding-api.open-meteo.com/v1/search · Weather: api.open-meteo.com/v1/forecast · Launches: ll.thespacedevs.com/2.2.0/launch/upcoming/?search=SpaceX

git branch -M main
